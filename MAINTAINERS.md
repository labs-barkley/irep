## Scopes

Scopes exist so that no single person has to hold everything, and so that a gap in one area is visible rather than silent.

- **Specification** — the protocol text, its versioning, and the rationale attached to each change.
- **Evidence** — `evidence/bibliography.md`, sourcing policy, and the annotation standard.
- **Validation** — pre-registration, pilots, and the responses to external review.
- **Implementation** — reference tooling and the conformity checklist.
- **Translations** — French first, then others.

Every scope other than Specification is currently unfilled. That is the honest state of the project, and the reason this file exists.

## Becoming a maintainer

Contribute. Get work merged. Keep doing it in an area that has a scope. A maintainer of record then proposes you in a public issue, and the proposal stands if no maintainer objects within fourteen days.

There is no application form, no title to request, and no seniority requirement. The only qualification is a record of merged work that others can read.
